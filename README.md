# 👟 AI-Powered Shoe Shopping Platform

AI-powered MERN eCommerce application for online shoe shopping with authentication, cart system, admin dashboard, and AI-assisted workflows.

## 🚀 Features
- JWT Authentication
- Product Management
- Shopping Cart
- Admin Dashboard
- Responsive UI
- AI-assisted workflows

## 🛠️ Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Redux Toolkit
- Tailwind CSS
